# daisywang.design — redesign

Astro site with a token-based design system. It ships with the **Refine** direction
(retro-corporate office by day, phosphor CRT terminal by night), in light and dark themes.

```sh
npm install
npm run dev          # http://localhost:4321  (password: see src/config.ts)
npm run build && npm run preview
npm run audit        # axe WCAG 2.1 AA + horizontal-overflow check (needs preview running)
npm run audit:shots  # same, plus screenshots in scripts/out/
npm run contrast     # checks semantic colour-token pairs per theme
npm run og           # re-renders the social share image, public/og.png
```

## How styling is layered

1. `src/styles/tokens/primitives.css`: raw palette, type scale, spacing, motion.
2. `src/styles/tokens/theme-refine.css`: maps primitives to **semantic tokens**
   (`--color-bg`, `--color-text-muted`, `--font-display`, `--radius-lg`, …) for
   `[data-theme="light"]` and `[data-theme="dark"]`, overrides component tokens
   (`--card-*`, `--btn-*`, `--tag-*`, `--hero-*`, `--figure-*`), and adds the Refine
   decorations (CRT monitor, ID badge, file labels, reading progress).
3. `src/styles/components/*.css`: components read semantic and component tokens only,
   with fallbacks (`var(--card-radius, var(--radius-lg))`).

To restyle the site, edit the theme file. The earlier explorations (Studio, Craft, Alloy,
Press, Prism, Resort) are kept in `src/styles/tokens/explorations/`. To bring one back,
import it in `src/layouts/BaseLayout.astro`, add it to `STYLES` in `src/config.ts`, and
add its fonts to the Google Fonts link. The style switcher appears automatically when
there is more than one style.

## Content

- Projects: `src/content/projects/*.md(x)`. Set `migrated: true` and write the body in
  MDX to publish a case study at `/work/<file-name>/`. Otherwise the card links to `href`.
  Set `archive: true` for the Earlier work list.
- Case-study building blocks in `src/components/case/`:
  - `Section`: eyebrow, heading and body.
  - `Figure`: an image; add `wide` to make it full width, or `narrow` for a single dialog or small UI.
  - `Compare`: before and after images.
  - `Split`: an image beside text.
  - `Quote`, `Callout`.
  - `Points`: a highlighted list.
  - `Stats`: big numbers.
  - `Video`: a muted loop with controls; it only autoplays when motion is allowed.
  - `Gallery`: a grid of smaller images with optional captions.
  - `AnimatedImage`: an animated WebP/GIF with a Play/Pause button (poster only under reduced motion).
  - `Toolkit`: tools, methods and skills.
- About page copy and ID badge text: `src/data/about.ts`.
- Hero monitor (number field, progress bins): `src/components/Hero.astro`.
- Site settings (email, resume, GA4 ID, password gate): `src/config.ts`.

## Assets

- `public/og.png`: the social share image, generated by `scripts/make-og.mjs`.
- `public/images/`: covers and case-study images. Oversized PNGs were downscaled to 2400px.
- `public/videos/boss-cta.mp4`
- `public/images/edit-image/`: Edit image case study visuals, cropped from the Figma deck at 2× with
  the slide backgrounds removed (WebP with transparency). Its diagrams are HTML (`.c-diagram`).
- The Refine monitor, badge, barcode and 404 are pure CSS, with no image files.
- Sharpness: `src/lib/imageSize.ts` reads each image's real pixel size at build time (including
  photos wrapped in SVG) and never displays it wider than half that, so it stays crisp on 2× screens.

## Before launch

- Add a GA4 ID.
- Convert the large raster-in-SVG images (some are 1–3 MB) to WebP/AVIF.
- Deploy `dist/` with a GitHub Pages Actions workflow, and keep `CNAME`.
